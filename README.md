# 🐍 بايثون بالعربي — منصّة تعلّم بايثون التفاعلية

منصّة تعليمية بالعربية الفصحى المبسّطة، تعلّمك بايثون من الصفر عبر **مستويات متدرّجة**، وأمثلة هي الأقصر ممكنة، وشرح لكل سطر كأنك لم تبرمج من قبل، مع **تشغيل الكود داخل المتصفح** (Pyodide).

## التشغيل

لا يوجد نظام بناء ولا تثبيت. اختر إحدى الطريقتين:

```bash
# الطريقة 1: افتح الملف مباشرة
index.html

# الطريقة 2: خادم محلي (يُفضَّل)
npx serve .          # أو:  python -m http.server 8000
```

> يلزم اتصال بالإنترنت عند أول زيارة لتحميل Pyodide (~10MB) والخطوط من CDN؛ بعدها يخزّنها المتصفح.

## بنية المشروع

```
index.html              نقطة الدخول (ترتيب تحميل السكربتات مهم)
css/styles.css          الثيم الداكن (افتراضي) + الفاتح، RTL أولاً
js/
  core.js               مساحة الأسماء PL، سجلّ المستويات، أدوات DOM، نص غني [[كود]] **غامق**
  store.js              حفظ التقدّم (localStorage) + منطق فتح المستويات
  runner.js             Pyodide داخل Web Worker + إدارة input() + ترجمة الأخطاء للعربية
  editor.js             محرّر كود مبني من الصفر (تلوين، ترقيم، إزاحة تلقائية، Ctrl+Enter)
  workspace.js          الجهة اليسرى في الدرس: محرّر + نتائج + إدخال + فحص التحدّي
  views.js              لوحة التحكم، صفحة المستوى، شاشة الدرس (تقسيم)، الاختبار
  app.js                الترويسة + التوجيه (hash router)
data/
  level1-variables.js   المستوى 1: الطباعة، المتغيرات، الأنواع، f-string، input
  level2-conditionals.js المستوى 2: المقارنة، if، else، elif، and/or
  level3-loops.js       المستوى 3: for/range، for مع القوائم، while، break، continue
  roadmap.js            المستويات 4–8 (مقفلة، "قريباً")
```

## المسارات (Routing)

| المسار | الشاشة |
|---|---|
| `#/` | لوحة التحكم وتقدّمك |
| `#/level/:levelId` | قائمة دروس المستوى |
| `#/level/:levelId/lesson/:lessonId` | الدرس (شاشة مقسومة: شرح ⟷ محرّر) |
| `#/level/:levelId/quiz` | اختبار المستوى |

## قواعد التقدّم

1. الدرس يكتمل عند **حلّ تحدّيه** (يُفحَص تلقائياً بتشغيل الكود).
2. الاختبار يُفتح بعد إكمال **كل دروس المستوى**، ويُجتاز بعدد إجابات صحيحة محدّد.
3. المستوى التالي يُفتح عند **إكمال دروس المستوى الحالي + اجتياز اختباره**.

## بنية الدرس (قالب المحتوى)

كل درس ملتزم بالقواعد البيداغوجية نفسها:

```js
{
  id, title, minutes,
  intro,                         // الفكرة في جملة
  example: { code, explain: [ { line, part, text } ] },   // أبسط مثال + شرح ELI5 لكل سطر/جزء
  notes: [ ... ],                // تنبيهات
  useCases: [ { icon, title, text } ],   // «أين نستخدم هذا في الواقع؟» (3–5 حالات)
  challenge: { prompt, expected, starter, hint, solution, check(out, code) }
}
```

لإضافة مستوى جديد: انسخ `data/level3-loops.js`، غيّر `id` و`order`، ثم أضف وسم `<script>` في `index.html`، واحذف المستوى المقابل من `roadmap.js`.

## ملاحظات تقنية

- **Web Worker**: الكود يعمل خارج الخيط الرئيسي؛ الحلقات اللانهائية لا تجمّد الصفحة، ويوجد زر إيقاف ومهلة 8 ثوانٍ.
- **`input()`**: لا يمكن للـ Worker الانتظار المتزامن، لذلك نستعمل "إعادة التشغيل": عند طلب إدخال جديد يُوقَف البرنامج، يظهر حقل للمستخدم، ثم يُعاد التشغيل مع تمرير كل الإجابات السابقة (مناسب لبرامج التعلّم الحتمية).
- المحرّر: `<textarea>` شفاف فوق طبقة `<pre>` ملوّنة، مع إبراز السطر المشروح عند تمرير الفأرة على الشرح.
